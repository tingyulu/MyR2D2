MyR2D2 Cheat Sheet

12 skills · when to use · what to say 🤖

Wrap-up & Handoff

/save-all
Before a reboot: save what's only in the chat, and verify it
"save-all"·"about to reboot"·"wrapping up for today"
/dropoff
Hand a task and its full context to another session
"hand this off to X"·"pass this to the next session"
/pickup
Read handoff cards and take over; run it at session start
"pickup"·"anything handed off to me?"

Work Journal

/mission-log
Zero-token harvest of a day's session activity (read-only)
"what did I work on today"·"mission log"
/daily-debrief
Turn that harvest into a daily report (needs mission-log)
"daily debrief"·"write up my day"
/weekly-debrief
Roll 7 dailies into a weekly (needs the two above)
"weekly debrief"·"wrap up my week"

Kickoff & Quality

/new-mission
3+ steps or hard to undo: ask → plan → your go → report
"mission brief"·"plan before doing"
/damage-report
Five self-review questions before reporting back
"damage report"·"self-review"
/ai-review
Get a second opinion from another model, then digest it
"second opinion"·"cross-model review"
/ai-search
Live web answers with citations; says so when not found
"fact-check this"·"what is the latest"
