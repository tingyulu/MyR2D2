收工與交接

/save-all
重開機／收工前，把只活在對話裡的東西落地並驗證
「save-all」·「要重開機了」·「關機前收尾」
/dropoff
把一件事連同脈絡交給另一個專案／未來 session
「交接給 X」·「推球給 X」
/pickup
讀交接卡並接手；session 開場跑一次防漏接
「接手」·「pickup」·「看交接」

工作日誌

/mission-log
零 token 收割某天的 session 活動骨架（只讀不寫）
「今天做了什麼」·「mission log」
/daily-debrief
由骨架產某天日報（需 mission-log）
「日報」·「daily debrief」
/weekly-debrief
彙整 7 份日報成週報（需上面兩支）
「週報」·「這週做了什麼」

開工與收尾品質

/new-mission
三步以上或做錯難回頭：先問→計畫→點頭才動手→收尾報告
「新任務」·「開工簡報」·「先問我再做」
/damage-report
收尾寫回報前的五問自檢
「收尾自檢」·「跑五問」
/systems-check
定期體檢規則、skill、log、security；只找不修、開交接卡
「系統自檢」·「跑自檢」·「體檢」
/ai-review
產出送另一個模型二審，消化意見再回報
「送二審」·「跨模型 review」
/ai-search
帶引用的即時網路查證，查不到就說查不到
「查證」·「上網查一下」
